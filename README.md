# Proyecto Final POO - Sistema Integrado en Java Swing

Repositorio del proyecto final de la asignatura Programación Orientada a Objetos. Aplicación de escritorio desarrollada en Java utilizando la librería Swing para la gestión integral de procesos.

---

## 📌 Características Principales

* **Interfaz de Usuario:** Diseñada con componentes gráficos Java Swing.
* **Paradigma POO:** Uso extensivo de clases, herencia, polimorfismo y encapsulamiento.
* **Estructura Modular:** Separación clara entre la interfaz gráfica y la lógica del negocio.
* **Manejo de Excepciones:** Control de errores de entrada para evitar fallos durante la ejecución.

---

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** Java
* **Interfaz Gráfica:** Java Swing / AWT
* **IDE:** NetBeans IDE
* **Gestor de Construcción:** Ant (`build.xml`)
